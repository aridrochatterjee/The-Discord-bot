# Contributing to THE Bot

Thanks for your interest in contributing to The Bot! 🚀

CommunityOS is an open-source Discord community management platform, and contributions of all sizes are welcome.

Whether you're fixing a typo, improving documentation, fixing a bug, or building a new feature, we appreciate your help.

## Before You Start

Please check the existing issues and pull requests before starting work to avoid duplicate efforts.

If you're planning a large feature or major architectural change, open an issue first so we can discuss the approach.

## Getting Started

### 1. Fork the repository

Click the **Fork** button at the top of the CommunityOS GitHub repository.

### 2. Clone your fork

```bash
git clone https://github.com/YOUR-USERNAME/communityos.git
cd communityos
```

### 3. Create a branch

Create a new branch for your changes:

```bash
git switch -c feature/your-feature-name
```

For bug fixes:

```bash
git switch -c fix/your-bug-name
```

## Making Changes

Keep your changes focused on one purpose whenever possible.

Before submitting a pull request:

- Make sure your code works.
- Follow the project's existing code style.
- Add or update tests when appropriate.
- Run the project's checks and linters.
- Do not commit secrets, API keys, or `.env` files.

## Commit Messages

Use clear commit messages.

Examples:

```text
feat: add warning moderation command
fix: handle missing database connection
docs: improve installation instructions
refactor: simplify command handling
```

## Submitting a Pull Request

1. Push your branch to your fork.
2. Open a Pull Request to the CommunityOS repository.
3. Clearly explain what your changes do.
4. Wait for review and feedback.

Please keep pull requests focused. Avoid combining unrelated changes into one pull request.

## Code Review

Pull requests may receive feedback or requested changes.

Don't worry — review comments are part of open-source development and are meant to improve the project.

## Community Guidelines

Be respectful and constructive.

We're building CommunityOS together, and contributors of all experience levels are welcome.

Happy building! 💻🚀
